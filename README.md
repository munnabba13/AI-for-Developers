# AI for Developers

A first Node.js project by munna. CommonJS app with `dotenv` for environment variables.

## Requirements

- Node.js (current LTS recommended)

## Setup

```bash
npm install
```

Copy environment values into a `.env` file in the project root. `dotenv` will load them at runtime once you wire it in your entry file.

## Project layout

| File            | Role                                      |
|-----------------|-------------------------------------------|
| `package.json`  | Package name, scripts, and dependencies   |
| `index.js`      | Declared entry point (`main`)             |
